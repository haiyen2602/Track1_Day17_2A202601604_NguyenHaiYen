# Interview Folder

Thư mục tối thiểu khi nộp:

```text
interview/
├── notes.md
└── recording.m4a
```

Có thể thay recording bằng:

```text
interview/recording_link.md
```

## Quy tắc
- Chỉ ghi âm khi interviewee đồng ý.
- `notes.md` phải là record của lượt bạn làm interviewer.
- Không cần nộp transcript nếu đề không yêu cầu.
- Không bịa quote hoặc dữ liệu.
